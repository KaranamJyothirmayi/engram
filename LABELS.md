# GitHub Labels

This document explains the labels used in this repository.
Labels help categorise issues and PRs and make it easier for contributors to find work that suits them.

## Type — `type:*`

| Label | Description |
|---|---|
| `type:bug` | Something doesn't work as expected |
| `type:enhancement` | A new feature or improvement |
| `type:docs` | Documentation is missing or needs updating |
| `type:testing` | Test coverage or quality |
| `type:maintenance` | Cleanup, refactoring, version bumps |
| `type:security` | A security-related issue or fix |

## Priority — `priority:*`

| Label | Description |
|---|---|
| `priority:critical` | Needs immediate attention |
| `priority:roadmap` | Planned and on the roadmap |
| `priority:contrib-welcome` | Not on the short-term roadmap, but contributions are welcome |

## Needs — `needs:*`

| Label | Description |
|---|---|
| `needs:triage` | Newly opened, not yet reviewed |
| `needs:more-info` | Needs more detail from the author |
| `needs:discussion` | The right approach is unclear |
| `needs:repro` | Cannot reproduce — author should provide steps |

## Area — `area:*`

| Label | Description |
|---|---|
| `area:core` | Core memory engine (`engram/`) |
| `area:api` | Public Python API (`__init__.py`) |
| `area:cli` | Command-line interface |
| `area:mcp` | MCP server integration |
| `area:nlp` | NLP / extraction layer |
| `area:docs` | Documentation and README |
| `area:ci` | CI/CD workflows and tooling |

## Workflow — `workflow:*`

| Label | Description |
|---|---|
| `workflow:do-not-merge` | PR should not be merged yet |
| `workflow:breaking-change` | Contains a breaking API change |

## General

| Label | Description |
|---|---|
| `good first issue` | Suitable for new contributors |
| `help wanted` | Maintainer would appreciate community help |
| `stale` | No activity for 30 days — will be closed if no response |
